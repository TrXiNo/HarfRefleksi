# Harf Refleksi

Türkçe Q klavyedeki harflerin konumlarını öğrenmek ve 10 parmak klavye kullanımını geliştirmek için hazırlanan C# WinForms uygulaması.

## Özellikler

- Rastgele Türkçe harf gösterimi
- Türkçe Q klavye görselleştirmesi
- Doğru tuşta yeşil, yanlış tuşta kırmızı geri bildirim
- Doğru ve yanlış basış sayacı
- Doğruluk oranı
- Pratik süresi
- Krem ve kahverengi arayüz
- `Esc` ile oturumu sıfırlama

## Kullanılan Teknolojiler

- C#
- .NET 8
- Windows Forms

## Çalıştırma

1. Projeyi bilgisayarınıza indirin.
2. `HarfPratik.sln` veya `.csproj` dosyasını Visual Studio ile açın.
3. Projeyi çalıştırın.
